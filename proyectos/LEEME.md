# Proyectos

Un archivo por proyecto (copia `_plantilla.md`). El script calcula el % con las submetas: sí = 100 %, parcial = 50 %, no = 0 %, o un número (ej. 30 %). `?` no cuenta.

- `foco: sí` → sale arriba con ⭐. Máximo 3 a la vez.
- `estado: pausado` → ⏸, sale abajo.
- Ritmo: 🔴 si quedan ≤ 7 días y va por debajo del 80 %; 🟡 si quedan ≤ 30 días y va por debajo del 50 %.
- Para actualizar desde un proyecto de Claude o ChatGPT: escribe `/estado` ahí y pega el bloque en Claude Code o Codex.
