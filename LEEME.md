# CENTRO DE MANDOS — puesta en marcha (fase 1)

## 1. Colócalo
Descomprime la carpeta `centro-de-mandos` en Documentos.

## 2. Claude Code (app de escritorio)
1. Abre la app, ve a la pestaña Code y elige la carpeta `centro-de-mandos`.
2. Escribe `/hoy`.
3. La primera vez te pedirá los datos que faltan (`?` en METAS.md).

## 3. Codex (app de Codex con tu cuenta de ChatGPT Plus)
1. Abre la misma carpeta.
2. Escribe `/hoy` o "haz el plan de hoy". Codex lee `AGENTS.md` y las skills de `.agents/skills/`.

Usa la que tengas a mano: las dos escriben en los mismos archivos y lo apuntan en `log.md`.

## 4. Rutina (lo único que tienes que hacer)
- Por la mañana: `/hoy`
- Por la noche: `/cierre` (los domingos incluye la revisión semanal)
- Cuando tengas un dato: "actualiza peso a 110" o "actualiza ahorrado a 160"

## 5. Fases siguientes (no adelantarse)
- Semana 2: `proyectos/` (UPV, BASTO, Transvia, agentes) con sus propias submetas.
- Semana 3: panel visual en Claude y proyecto en ChatGPT con resumen de los lunes.
- Mes 2: subir a GitHub privado, plugin de Codex para Claude Code y conectar Calendar.
